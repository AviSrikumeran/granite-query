# GraniteQuery full-name navigation

The user approved the full-name block-letter preview and explicitly requested publication. This replaces the live GQ navigation mark with GRANITEQUERY in the same five-row glyph lettering. The original G and Q silhouettes, Q tail, magenta material, rigid slow turn, and travelling shine are preserved.

The approved artwork contains 222 symbols. Desktop uses a 600 by 88 pixel transparent canvas, shifted down 6 pixels. At widths up to 560 pixels the name stacks as GRANITE / QUERY on a canvas up to 360 by 132 pixels. Navigation collapses to the existing Menu control up to 1280 pixels to avoid squeezing the artwork. Mobile menu placement and homepage content spacing account for the taller header.

The shared loader retains its accessible home link, keyboard pause controls, reduced-motion behavior, static text fallback, offscreen suspension, and context restoration. Light reading surfaces retain a deeper magenta palette.
