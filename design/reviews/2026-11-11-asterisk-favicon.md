# Approved asterisk favicon

The user explicitly approved publishing the larger square-ended asterisk with maximum faceted contrast. This exports that exact preview geometry and palette to SVG, 16/32/48px PNGs and a multi-resolution ICO. The asterisk is static and transparent, with white/pink upper facets, a neon-purple face and deep-purple extrusion.

The drawing uses a 16-unit square: center (7.6, 7.4), arm radius 6.8, arm half-width 2, bevel 0.9 and extrusion (0.65, 0.8). Its combined bounds are (0.8, 0.511) to (15.05, 15.089), keeping the complete shape inside the favicon square. The dependency-free exporter preserves the approved polygon coordinates, painter order and colors.

Static versioned icon links are added to all nine public website/research page heads. Relative paths support both the custom domain and GitHub Pages project mirror. The root favicon.ico also supports automatic browser lookup. No navigation artwork, research content, page layout or inference behavior changes.

Validation: SVG parses, PNG headers match each size, ICO contains 16/32/48px images, all nine HTML bodies are byte-for-byte preserved, and browser checks verify the SVG and raster exports at native sizes on white and black backgrounds. Production is checked after deployment.
