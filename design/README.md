# Granite Query: website design research

Updated 4 November 2026. Status: integrated research website with preserved motion and material studies; owner review of the new presentation is pending.

The goal is a distinctive, enterprise-quality public research website: readable evidence, clear project status, carefully built components, and purposeful motion. This is a presentation-quality goal, not a claim that the model or service is production-ready.

## Feedback to collect

For each component ID in the study, record Keep / Adapt / Pass, plus the specific quality liked or disliked. Judge geometry, density, movement, and information clarity separately from the reference site's colors. For movement, a still image is only a starting point: the next review needs a working isolated specimen.

The original component captures remain reference candidates. The later playground verdicts are recorded above and in the workflow. GitHub source links establish implementation evidence where available; they do not establish conversion performance. Social-platform reactions have not been researched in this pass and should not be presented as consensus. User-supplied X or Reddit links can be appended with the specific claim, context, and whether we agree.

## Capture provenance
