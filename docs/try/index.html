What this interface does

This is a bounded research trial of ibm-granite/granite-4.2-3b. The server advertises one pinned original checkpoint. This page requests greedy, non-thinking output with a short output limit; it does not train, improve or evaluate the model.

Questions travel through this website’s gateway to its authenticated backend. Provider credentials stay on the server. Only the last request ID and completion state are retained in this tab’s session storage; question text and model output are not stored there by this page.

A cancelled browser request does not prove the backend stopped. An uncertain attempt is never automatically replayed.
