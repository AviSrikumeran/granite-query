# Playground work

Before changing an experiment, read `design/DESIGN_WORKFLOW.md` and `design/README.md` from the repository root. Carry forward the recorded preferences and use the bounded review process.

Keep new directions in isolated folders. Preserve accepted animation code and the research homepage unless the user's active request authorizes changing them. A navigation fix may add or repair links without changing a study's geometry, material or motion.

Every new specimen must be discoverable from `docs/playground/experiments/index.html` and provide an All experiments link back. Keep paused review URLs separate from normal autoplay entry links. Keep controls usable on narrow screens.

Do not change training code, data exporters or research results as part of visual work. Use the freshest remote tree and preserve unrelated updates when publishing through the GitHub connector. Avoid committing the shared workspace wholesale.
