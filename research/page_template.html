What is inside the checkpoint?

Each projection is a learned array. Shape comparisons reveal structure; scalar magnitudes cannot explain which model reasons better. All 3,659,737,600 downloaded Granite values were scanned: no nonfinite values were found.

    What would sparse upcycling change?
    Replace selected dense MLP blocks with cloned experts and route each token to a subset. This adds capacity while reusing learned weights. It does not automatically shorten answers or accelerate the original model.
    Total capacityIncludes added bias-free routers
    BF16 weight storageExcludes all training and runtime state
    MLP arithmetic proxySelected blocks only; routing costs extra
    Default: 8 blocks × 4 experts × top 1 → about 5.17B total parameters and 10.34 GB of weights. This machine's 12 GB GPU does not thereby fit training. Kernel support, activations, optimizer memory and dispatch overhead require measurement.
    Original Sparse Upcycling paper · Drop-Upcycling follow-up
    Decision gate: first locate a bottleneck and validate an affordable dense improvement. Before sparse training, require conversion equivalence, save/reload checks, routing diagnostics and a funded dense-control comparison. The current shared credits are not a new budget.
